Nibble a language for a 1977 machine

Write a program on the left and it is compiled to real CHIP-8 machine code, then run on the right by an emulator of that machine. The bytes underneath the screen are the actual output.

The compiler is about three hundred lines and has no dependencies. It is checked by compiling programs and running them on the machine, then looking at which pixels came on, so the tests exercise the whole path rather than the parser alone. The emulator is the one from my CHIP-8 project, which runs every program in the community archive. The source is on GitHub.
